Place the official mihomo Windows executable here and rename it to mihomo.exe.

Official releases: https://github.com/MetaCubeX/mihomo/releases
64-bit Windows 7: choose windows-amd64-v1 (baseline CPU instruction set).
32-bit Windows 7: choose windows-386.
Extract the downloaded ZIP first. Do not rename a ZIP to EXE.

Alternatively choose the executable in Aurora Proxy > Settings.
